Apps Script
Программа на серверах Google, привязанная к одному Google-аккаунту. Код пишет ИИ-агент. От вас нужно нажать «Выполнить» и дать доступ.
Code.gs
Логика: откуда брать данные, что посчитать, что сохранить.
index.html
Сама страница, то есть всё, что видит человек: вёрстка, цвета, кнопки. Именно его показываем клиенту как прототип.
Часовой пояс
Настройка проекта скрипта (файл appsscript.json). Ставится по городу клиента: Москва — Europe/Moscow, Екатеринбург — Asia/Yekaterinburg, Красноярск — Asia/Krasnoyarsk. От пояса зависят даты, «сегодня», просрочки и время запуска по расписанию. Если пояс не тот, даты съезжают на день.
Свойства скрипта
Сейф скрипта: ключ Gemini, вебхук Битрикса, ID таблиц. Вносит их человек руками. В коде, в чате и в таблицах их быть не должно.
Развёртывание, ссылка /exec
Публикация скрипта. Ссылка /exec — адрес, по которому страница получает данные. Если обновлять то же развёртывание, ссылка не меняется.
Триггер
Запуск по расписанию, например «раз в час забрать данные из Битрикса».
Google Cloud Console
Пульт сервисов Google. Здесь создают проект, ключ Gemini и подключают Firebase.
Firebase Hosting
Бесплатный короткий адрес для страницы: имя.web.app. Страница там — витрина, а данные она берёт у скрипта.
GitHub Pages
То же самое на GitHub, адрес вида имя.github.io/проект. Удобно для внутренних инструментов.
Вебхук Битрикса
Секретная ссылка, по которой скрипт читает Битрикс без логина. Кто её знает, тот видит данные.
API
Вход в систему для программ. Система даёт ключ, по нему скрипт сам забирает данные. Российские программы иногда пускают к API только из России — тогда вместо API делают выгрузку файлом.
Ключ API
Пароль к API. Например, по ключу Gemini понимает, чей запрос и в чьи лимиты его записать.
clasp, firebase-tools
Программы, которыми ИИ-агент заливает код. Запускает их агент. От вас — один раз выполнить команду входа, которую он даст, и подтвердить вход в браузере.
Окно инкогнито
Главный приём: в нём открыт только один Google-аккаунт. Половина ошибок — от того, что в браузере открыт «не тот» аккаунт.

5. Откуда берутся данные? можно несколько
Про API — важно. Данные можно забирать из любой программы, у которой есть API. API — это вход в систему для программ: система даёт ключ, по нему скрипт сам забирает данные, как сейчас из Битрикса. Но российские программы иногда пускают к API только из России, а скрипт Google работает с зарубежных серверов. Тогда остаётся только выгрузка файлом — как, например, из 1С: программа сама по расписанию сохраняет отчёт в папку Google Диска, скрипт берёт свежий файл.

Ответы формы, договорённости, журнал использования. Если страница только показывает — «Нет».
