# Стартовый шаблон живой страницы

Заготовка для страницы, которая сама обновляется из Google Таблицы, Битрикс24 или другой системы:
**источник → Apps Script → страница**. Собрана из рабочих проектов JTBD, в ней уже решены ошибки,
на которых мы обжигались. Пошаговый маршрут — в [навигаторе](https://karina120089-hash.github.io/jtbd-navigator/).

> Шаблон — основа, а не закон. В каждом проекте будут свои корректировки: другие данные, права, требования клиента, изменившиеся экраны Google. Меняйте то, что нужно задаче, и записывайте отличия в «Паспорт проекта».

## Что внутри

| Файл | Что это |
|---|---|
| `gas/Code.js` | Сервер: забирает данные, кэширует, отдаёт странице, принимает записи, зовёт ИИ |
| `gas/index.html` | Сама страница. Один файл на все случаи: внутри Apps Script, на Firebase и на GitHub |
| `gas/prompt.js` | Текст промта для ИИ внутри страницы — правится без кода |
| `gas/appsscript.json` | Настройки проекта: **часовой пояс**, доступ «Все», запуск от имени владельца |
| `tools/build.py` | Вписывает ссылку `/exec` в страницу для Firebase (`public/`) или GitHub Pages (`docs/`) |
| `firebase.json` | Настройки Firebase Hosting: без кэша (обновления видны сразу) и без индексации |

## Как начать

Скажите своему ИИ-агенту в пустой папке проекта:

> Скачай стартовый шаблон: `git clone --depth 1 https://github.com/karina120089-hash/jtbd-navigator.git tmp-template`,
> скопируй содержимое папки `tmp-template/template` в эту папку и удали `tmp-template`.
> Прочитай `README.md` и работай на основе шаблона.

## Правила для ИИ-агента

1. **Основа — этот шаблон.** Меняй под задачу: `TITLE`, загрузку в `sync()`, состав `payload_()`,
   отрисовку `render()` и `DEMO` в `index.html`. Ненужные блоки (Битрикс, запись, ИИ) удаляй целиком.
   Готовые решения (кэш частями, повторы запросов, «Обновить», reqId для ИИ) не переписывай.
2. **Форма данных одна.** `DEMO` в `index.html` = то, что отдаёт `payload_()`. Прототип делаем на `DEMO`,
   потом подключаем сервер — страница не меняется.
3. **Секреты — только в свойствах скрипта.** Вебхук, ключи, пароли не пишем в код, файлы, таблицы и коммиты.
   Если человек дал вебхук в чате — используй его для проверки, но никуда не записывай.
4. **Часовой пояс.** Перед первой заливкой впиши пояс клиента в `gas/appsscript.json` (`timeZone`).
   `clasp create` перезаписывает этот файл — после него проверь `timeZone` ещё раз.
5. **Ни одной цифры, имени или даты в коде страницы** — всё из данных.
6. **Обновление без смены ссылки:** `clasp push --force`, затем `clasp create-deployment -i <ID развёртывания>`.
   Без `-i` появится новая ссылка `/exec`, и страница на Firebase/GitHub перестанет получать данные.
7. **Поменял формат данных — смени `CACHE_KEY`**, иначе страница покажет старый кэш.
8. **6 минут.** Apps Script обрывает запуск через 6 минут: большие загрузки дели на части.
9. **В конце заполни раздел «Паспорт проекта» ниже.**

## Первая настройка (делает агент, человек подтверждает вход)

```bash
cd gas
npx @google/clasp@3 login                    # один раз: выбрать аккаунт скрипта в браузере
npx @google/clasp@3 create --type standalone --title "Название страницы" --rootDir .
# clasp create перезаписал appsscript.json → вернуть timeZone и webapp из шаблона
npx @google/clasp@3 push --force
npx @google/clasp@3 create-deployment --description "v1"   # ID развёртывания записать в паспорт
```

Затем человек в редакторе скрипта: выбрать `setup` → **Выполнить** → выдать разрешения.
Свойства скрипта: **Настройки проекта → Свойства скрипта**.

| Свойство | Когда нужно |
|---|---|
| `SOURCE_SHEET_ID` | источник — Google Таблица (ID из ссылки между `/d/` и `/edit`) |
| `BITRIX_HOOK` | источник — Битрикс24 |
| `API_KEY` | другая система с API |
| `GEMINI_API_KEY` | ИИ на Gemini. Модель меняется свойством `LLM_MODEL` |
| `LLM_PROVIDER` = `gigachat`, `GIGACHAT_AUTH_KEY` | ИИ на GigaChat вместо Gemini |
| `ALERT_EMAIL` | кому писать об ошибках загрузки; по умолчанию владельцу скрипта |
| `SHEET_ID` | ставит сам скрипт — служебная Таблица |

Расписание: в редакторе запустить `installTrigger` (раз в час) или вызвать `installTrigger(24)`.

## Где живёт страница

- **Сам Apps Script** — ничего не собирать: ссылка `/exec` и есть страница.
- **Firebase:** `python3 -I tools/build.py <ссылка /exec>` → `npx firebase-tools deploy --only hosting --project <проект> --account <почта>`.
- **GitHub Pages:** `python3 -I tools/build.py <ссылка /exec> docs` → коммит → в настройках репозитория Pages: ветка `main`, папка `/docs`.

## Проверка

- `<ссылка /exec>?format=json` в окне инкогнито — JSON с настоящими данными, без страницы входа.
- `testAgent` и `listModels` в редакторе — если подключён ИИ.
- Чек-лист сдачи — в навигаторе, шаг «Проверка».
